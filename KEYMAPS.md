# Neovim Cheat Sheet

## Custom Keymaps

| Key | Action |
|-----|--------|
| `Ctrl-p` | Find files |
| `Ctrl-r` | Global grep search |
| `u` | Undo |
| `U` | Redo |
| `J` / `K` | Scroll down/up |
| `gh` | LSP Hover (replaces K) |
| `<leader>fy` | Copy relative path |
| `<leader>fY` | Copy absolute path |

## Navigation (Tmux + Vim)

| Key | Action |
|-----|--------|
| `Ctrl-h/j/k/l` | Navigate splits/panes |
| `Ctrl-\` | Previous split |

## Git

| Key | Action |
|-----|--------|
| `<leader>gB` | Open file in GitHub |
| `<leader>gY` | Copy GitHub URL |
| `<leader>gg` | Lazygit |
| `<leader>gb` | Git blame line |
| `<leader>gd` | Diff this |

## Files & Search

| Key | Action |
|-----|--------|
| `<leader><space>` | Find files |
| `<leader>sg` | Grep (search text) |
| `<leader>sf` | Find files |
| `<leader>sr` | Resume last search |
| `<leader>e` | Explorer |

## LSP

| Key | Action |
|-----|--------|
| `gd` | Go to definition |
| `gr` | References |
| `gI` | Go to implementation |
| `gy` | Go to type definition |
| `<leader>ca` | Code action |
| `<leader>cr` | Rename |
| `<leader>cd` | Line diagnostics |
| `]d` / `[d` | Next/prev diagnostic |

## Windows & Buffers

| Key | Action |
|-----|--------|
| `<leader>-` | Split horizontal |
| `<leader>\|` | Split vertical |
| `<leader>bd` | Delete buffer |
| `<leader>qq` | Quit all |

## Editing

| Key | Action |
|-----|--------|
| `Alt-j/k` | Move line down/up |
| `gc` | Toggle comment (visual) |
| `gcc` | Toggle comment (line) |
| `Tab` | Accept completion |
| `Ctrl-n/p` | Next/prev completion |

## Misc

| Key | Action |
|-----|--------|
| `Ctrl-c` | Escape + clear highlight |
| `<leader>ur` | Redraw / clear hlsearch |
| `<leader>?` | Buffer keymaps |
